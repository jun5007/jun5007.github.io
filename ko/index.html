접근 방식, 결과, 배운 점, 다음 계획

처음의 접근 방식

Public Leaderboard 순위가 교과목 성적에 반영되었기 때문에 초기에는 Public 점수를 높이는 것을 우선 목표로 두었습니다. 여러 모델과 전처리 방식을 실험해 Public 1위를 기록한 뒤, Private에서도 일반화되도록 모델과 검증 방식을 조정했습니다. 이 과정에서 Public 순위가 3위와 5위로 내려가기도 했지만 최종 제출 모델은 다시 Public 1위를 기록했습니다.

잘된 점과 아쉬웠던 점

Public 결과로 수업 평가와 초기 목표 측면에서는 좋은 결과를 얻었습니다. 그러나 Final Private 118위는 Public 성능이 전체 테스트 데이터에 그대로 일반화되지 않았음을 보여주었습니다. 남아 있는 자료만으로 원인을 하나로 단정할 수는 없습니다. Public 점수를 반복해서 확인한 선택 과정이 해당 구간에 간접적으로 맞춰졌을 가능성과 로컬 검증이 Private 데이터 특성을 충분히 반영하지 못했을 가능성을 돌아보게 되었습니다.

배운 점

Public 순위와 일반화 성능은 서로 다른 기준이며, 리더보드 변화에 따라 계속 모델을 바꾸기보다 사전에 정한 로컬 검증 방식과 실험 기록으로 모델을 선택해야 한다는 점을 배웠습니다.

다음 대회에서 바꿀 점

앞으로는 모델·Fold·Random Seed별 Local Validation, Public과 로컬 점수 차이, 모델과 Feature 변경 내역, 제출별 선택 이유, 예측 확률 분포와 Calibration, 최종 모델 선택 기준을 체계적으로 기록하겠습니다.
