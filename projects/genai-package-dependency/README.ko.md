# 생성형 AI 패키지 의존성 네트워크 분석

## 프로젝트 개요

- 기간: **2026.03–2026.06**
- 유형: **팀 프로젝트**
- 주제: 생성형 AI Python 패키지 의존성 네트워크 분석

생성형 AI 생태계에서 사용되는 Python 패키지들이 서로 어떻게 의존하는지 분석한 프로젝트입니다. PyPI 메타데이터, 버전 스냅샷, 의존성 엣지, 대표적인 소스 코드 구조 레코드를 결합해 중심 패키지, 의존성 커뮤니티, 구조적으로 유사한 대안을 살펴봤습니다.

## 문제 정의

다음 네 가지 질문을 살펴봤습니다.

- 널리 알려진 생성형 AI 패키지가 의존성 네트워크에서도 구조적으로 중심에 있는가?
- 2022년부터 2026년까지 중요도가 높아진 기반 의존성은 무엇인가?
- 시간에 따라 상대적 중심성이 낮아진 패키지는 무엇인가?
- 같은 생태계에서 구조적으로 유사한 대안 패키지를 찾을 수 있는가?

## 데이터 출처

- 출처: [PyPI (Python Package Index)](https://pypi.org/)
- 수집 항목: 프로젝트 메타데이터, 릴리스 이력, 의존성 선언
- 구조 데이터: PyPI에서 제공되는 일부 패키지 배포 파일의 파일·import·symbol 구조
- 공개 스냅샷 기준일: **2026-06-16**

프로젝트 문서에는 공식 PyPI 메타데이터 API를 사용한 수집 과정이 설명되어 있으며, 공개 테이블에는 PyPI 프로젝트 URL과 메타데이터 필드가 포함되어 있습니다. 다만 수집 코드는 공개되어 있지 않아 정확한 엔드포인트 호출 순서와 전체 수집 파이프라인을 이 폴더만으로 재현할 수는 없습니다. 다운로드 수나 실제 패키지 사용량 통계는 포함하지 않습니다.

## 데이터 범위

- 생성형 AI 관련 Python 패키지 50개
- 5개 범주: LLM API, Framework/Agent, Model Runtime, App/Service, RAG/Vector DB
- 2022년 말부터 2026년 6월 16일까지 5개 시점 스냅샷 (`2026_current`는 실시간 값이 아닌 고정 데이터셋 라벨)
- 의존성 엣지 4,509건
- 로컬 전체 분석 데이터의 10개 선정 패키지 코드 구조 레코드 72,922건
- 공개된 `openai` 패키지 코드 구조 샘플 500행
- 네트워크 분석 결과 1,190행

## 데이터 및 라이선스 참고

공개 전 로컬 절대 경로를 제거했습니다. 코드 구조 샘플의 상대 경로는 원래 수집 작업 공간 내부 파일을 가리키며 레코드 맥락을 위해서만 남겨 두었습니다.

패키지 메타데이터와 구조 레코드는 PyPI에서 제공되는 배포 파일을 바탕으로 합니다. 각 상위 패키지의 라이선스는 해당 패키지에 그대로 귀속되며, 이 저장소가 상위 소스 코드에 새로운 라이선스를 부여하지 않습니다. 공개 샘플에는 소스 코드 본문이 아니라 경로, import, symbol 이름 같은 구조 필드만 포함됩니다.

이 폴더에는 프로젝트 단위 `LICENSE`나 `DATA_LICENSE.md`가 없습니다. 일부 패키지는 메타데이터의 라이선스 필드가 불완전하므로 해당 필드를 최종 재배포 허가로 해석해서는 안 됩니다. 재사용 전 관련 상위 라이선스와 저작자 표시 조건을 별도로 확인해야 합니다.
