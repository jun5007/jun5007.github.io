환율·산업 수익률 Walk-Forward 분석

KOSPI 대형주, USD/KRW 환율, 외국인 수급을 결합한 팀 프로젝트입니다. 공개 R 구현은 고정 산업 매핑과 시점별 동조 피처를 사용해 다음 달 산업 수익률을 비교합니다.

Problem 환율 변화가 산업별 수익률 예측에 주는 영향 확인
Published Implementation 과거 평균, Random Forest baseline, 동조 피처 추가 모델의 동일-fold 비교
Status 미래정보 누수 가능성을 수정했으며, 실데이터 성능은 원본 데이터 확보 후 재검증 필요
  • 공개 코드에는 K-Means가 없어 고정 산업 매핑 사용 사실을 명시
  • 각 기준월까지의 자료만 사용해 Lift 파트너와 동조 피처를 재계산
  • 확장형 Walk-Forward에서 단순 기준선과 두 Random Forest를 같은 fold로 비교
  • 원본 데이터 비공개로 현재 성능 수치는 게시하지 않음
